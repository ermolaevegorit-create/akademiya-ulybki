# Академия улыбки

Сайт стоматологической клиники «Академия улыбки» — Сочи, ул. Виноградная, 55/1, пом. 22.
Статические страницы без сборки: откройте `index.html` или положите папку на любой хостинг.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на github.com, например `akademiya-ulybki` (без README).
2. В этой папке выполните:

```bash
git init
git add .
git commit -m "Сайт «Академия улыбки»"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/akademiya-ulybki.git
git push -u origin main
```

3. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)`.
   Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/akademiya-ulybki/`.

## Перед боевым запуском

- Реальный домен вместо `https://akademiya-ulybki.ru` — в `robots.txt`, `sitemap.xml`, `llms.txt` и в мета‑тегах всех страниц.
- Номер счётчика Яндекс.Метрики: строка `<script>window.__METRIKA="";</script>` в каждой странице. Пусто — статистика выключена, счётчик подключается только после согласия на cookie.
- Часы работы, реквизиты аккредитации, цены, условия акции и промокода — черновики, отмечены пунктиром на страницах.
- Политику обработки персональных данных проверить у юриста.
