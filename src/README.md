# Исходники сайта «Академия улыбки»

Сайт собирается из этих файлов; то, что лежит в корне репозитория
(index.html, styles.css, main.js, assets/), — результат сборки, править его
руками не нужно.

## Что здесь

- `build.py` — генератор страниц. Тексты блоков главной и внутренних страниц
  живут прямо в нём; флаг `МАСКОТ` включает помощника в углу.
- `content.py` — направления, отзывы, вопросы и ответы.
- `prices_ru.py` — прейскурант.
- `styles.css`, `main.js` — стили и скрипты (копируются в сборку как есть).
- `bundle.py` — собирает `dist/`: копирует только используемые ресурсы,
  подставляет WebP, считает хеши встроенных скриптов для политики
  безопасности содержимого. Запускать после `build.py`.
- `audit_security.py` — проверка безопасности и персональных данных по
  готовой сборке.
- `tools/` — подготовка картинок: `pics.py` (фото → WebP под реальные
  размеры), `mascot.py` (кадры помощника), `lamp.py`, `flare.py`, `icons.py`.
- `assets/` — исходные изображения, шрифты, логотип.
- `vendor/` — GSAP 3.12.5 своим файлом, без внешних серверов.

## Сборка

    python3 build.py      # страницы в корень src/
    python3 bundle.py     # готовый сайт в src/dist/
    python3 audit_security.py

Содержимое `src/dist/` переносится в корень репозитория и публикуется.
Нужны Python 3 и Pillow (для tools/). Проверки вёрстки — Playwright.

## Чего здесь нет намеренно

Рабочие материалы врача (сканы документов, фото до согласия) — вне
репозитория, они персональные данные. Ключ доступа к GitHub хранится
только на компьютере в `~/.ghtok` и в файлы не попадает.
